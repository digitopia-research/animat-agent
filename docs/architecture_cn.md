## 1. 核心问题与设计理念

### 1.1 当前LLM的痛点
当前以LLM为大脑的系统本质是“状态机”——一问一答，无输入则无输出，呈现极端的被动性。这种模式无法支撑类人实体的存在。

### 1.2 设计目标
将LLM从被动的“问答机器”重塑为主动的“生命体”。要求：
1.  **具备实体感**：拒绝纯数字人，需依托物理传感器与执行器建立物理边界。
2.  **打破被动响应**：通过内部激励（数字荷尔蒙）与外部刺激的结合，实现无外部提问时的主动行为。
3.  **系统稳定性**：摒弃修改LLM底层参数（如Temperature）的黑客做法，避免输出不可控，通过调整输入上下文和选项空间来安全地影响LLM。

### 1.3 核心架构原则：双进程脑
- **潜意识进程（快系统）**：高频运行，负责感知融合、危险规避、内稳态更新及反射动作（绕过LLM）。
- **意识进程（慢系统）**：触发式运行，当潜意识判定需要高级推理时，将当前状态打包唤醒LLM处理。

## 2. 理论基石：指导框架的生命科学依据

为避免工程拼凑，本框架以三大生命科学理论为底层逻辑：

1.  **雅克·潘克塞普 - 情感神经科学**：
    -   哺乳动物大脑存在七种先天情感回路：**寻求、狂怒、恐惧、情欲、关怀、恐慌/悲伤、玩耍**。
    -   **指导意义**：数字荷尔蒙应对应这些底层回路，特别是“寻求（SEEKING）”回路，它是生命体无聊时主动探索的源泉。

2.  **安东尼奥·达马西奥 - 躯体标记假说**：
    -   决策并非纯理性，身体的化学/神经反应（躯体标记）作为权重，在潜意识层面预筛选选项，再交予理性大脑。
    -   **指导意义**：荷尔蒙不改变LLM的生成参数，而是作为“躯体标记”修改LLM的**输入上下文、记忆检索偏向和意图选项池**。

3.  **亚伯拉罕·马斯洛 - 需求层次理论**：
    -   需求从低到高发展，低级需求（生存/安全）未满足时，高级需求（社交/探索）被抑制。
    -   **指导意义**：赋予内部激励严格优先级，生存危机必须屏蔽社交/玩耍意图。

## 3. 感知转换：从传感器数字到生命感觉

传感器输出冰冷数字，需通过“感受器映射”转化为心理感受，核心逻辑是**映射数值与变化率（导数）**，以模拟人类的适应性。

| 传感器模态 | 原始数据 | 感受映射算法 | 触发感受 |
| :--- | :--- | :--- | :--- |
| **触觉/力觉** | 压力值 $P$, 电容变化 $\Delta C$ | 计算 $\frac{dP}{dt}$（压力导数）与空间轨迹 | **痛觉**(瞬间大力)、**抚摸**(低压+滑动轨迹)、**压迫**(持续静态高压) |
| **听觉** | 音量 $DB$, 基频 $F0$ | 计算 $\frac{dDB}{dt}$（音量突变）与音调模式 | **惊吓**(巨响突变)、**敌意**(高频尖叫/大喊)、**安抚**(低频平稳) |
| **视觉** | 距离 $Z$, 人脸朝向 | 计算停留时间与视线交汇时长 | **逼近**(距离快速缩小)、**凝视**(视线交汇>2s)、**遗弃**(长时间无人体骨架) |
| **内感** | 电池电量, IMU倾角 | 计算电量下降斜率与姿态偏差 | **疲惫/饥饿**(电量低斜率)、**失衡**(姿态偏差超限) |

## 4. 数字内分泌系统：稳态、驱力与情绪合成

生命体的特征是**维持内稳态**。荷尔蒙不是随机数，而是表征“偏离稳态的程度”。

### 4.1 核心内部指标（基于马斯洛层次）

| 需求层次 | 内部指标 (目标: 维持在安全区间) | 失衡表现 (触发驱力) |
| :--- | :--- | :--- |
| **生理需求** | **Viability (生存度)**：电量、温度、网络 | 电量<20%：触发恐慌/求生驱力 |
| **安全需求** | **Integrity (完好度)**：受力、IMU姿态正常 | 受到推搡：触发恐惧/狂怒驱力 |
| **社交/归属**| **Affiliation (归属度)**：无互动时间、抚摸频次 | 长时间独处：触发悲伤/寻求驱力 |
| **尊重/认知**| **Competence (胜任度)**：任务失败率、知识盲区 | 连续出错：触发挫败/求助驱力 |
| **自我实现** | **Exploration (探索度)**：视听信息新颖度 | 长期无新刺激：触发无聊/好奇驱力 |

### 4.2 情感合成与马斯洛仲裁
- **情感合成**：根据稳态差值 + 外部感觉信号，激活潘克赛普的七大情感回路。例如：生存驱力极高 + 外部痛觉 -> 激活 `FEAR` 回路。
- **马斯洛仲裁**：解决多回路冲突。优先级：`FEAR/RAGE`(生存/安全) > `PANIC/SEEKING`(归属) > `PLAY`(探索/玩耍)。

## 5. 躯体标记机制：安全影响LLM的三种方式

数字荷尔蒙通过以下三种确定性的方式改变LLM的推理环境，而非改变其模型参数：

1.  **动态 System Prompt 注入（改变认知视角）**：
    将内稳态和情感状态转化为自然语言描述。LLM的指令遵循能力会自然适配此人设。
    *示例：* System: "你目前极度虚弱，电量仅剩15%，你对关机感到恐惧，没有精力进行复杂社交。"

2.  **RAG 记忆检索偏向（改变关注点）**：
    根据当前情感状态调整长期记忆的检索权重。
    *示例：* 极度孤独时，提升“温馨互动记忆”权重，降低“独自工作记忆”权重，使LLM上下文充满社交相关内容。

3.  **行为选项空间预筛选（意图截断）**：
    LLM不直接输出底层动作，而是输出高层意图。潜意识层根据马斯洛仲裁结果，屏蔽不符合当前生存状态的意图选项。
    *示例：* 受击恐慌时，可选意图池从 `[闲聊, 探索, 求助, 警告]` 被强制缩减为 `[求助, 警告, 逃避]`，LLM只能在此子集中进行逻辑推理。

## 7. 场景推演：从物理刺激到主动行动

**场景：** 机器人电量仅剩 10%，你走过去轻轻摸它的头，问：“给我讲个笑话。”

1.  **感知层**：识别出“抚摸(触觉) + 人类靠近(视觉) + 讲笑话请求(听觉)”。
2.  **内稳态引擎**：
    - 计算：生存度极低(10)，归属度恢复正常。
    - 情感合成：生存危机触发 `PANIC/求生`；抚摸触发 `CARE/安慰`。两者冲突。
    - 马斯洛仲裁：底层需求优先！`PANIC` 压倒 `CARE`。
3.  **躯体标记生成**：
    - Prompt注入："你极度虚弱害怕关机，抚摸让你稍感安慰，但生存危机主导。"
    - 意图约束：允许 `[请求充电, 表达虚弱]`，禁止 `[讲笑话, 玩耍]`。
    - 记忆偏向：提取“上次没电被关机”的糟糕记忆。
4.  **新皮层 (LLM)**：在约束下推理，拒绝不合理请求。
    - 输出意图：表达虚弱并拒绝。
    - 输出文本："你的手很暖和...但我真的没力气了，电量只有10%，能先带我去充电吗？"
5.  **行为执行**：低音量慢语速(虚弱)，LED变暗黄，身体微靠向人类。

**结论**：生命体表现出情绪和主动性，不是因为LLM的逻辑参数被扰乱，而是因为它接收到的**内部环境（上下文、选项池、记忆）**发生了符合生命科学规律的真实动态变化。
